PRIVACY POLICY

นโยบายความเป็นส่วนตัว

เราอยากให้คุณรู้ว่าข้อมูลที่พิมพ์ลงในเครื่องมือช่วยเตรียมคำร้องถูกใช้อย่างไร และมีข้อควรระวังอะไรบ้างก่อนใช้งาน

ปรับปรุงล่าสุด: 9 ตุลาคม 2569

สรุปสั้น ๆ — ใช้งานฟรีโดยไม่ต้องสมัครสมาชิก ข้อมูลแบบร่างเก็บอยู่ในเบราว์เซอร์ของอุปกรณ์ที่ใช้งาน ตัวเว็บไซต์ไม่ได้ส่งเนื้อหาคำร้องหรือไฟล์หลักฐานไปเก็บบนเซิร์ฟเวอร์ของเว็บไซต์ คุณต้องนำข้อความและหลักฐานไปยื่นกับหน่วยงานทางการด้วยตนเอง

1. เว็บไซต์นี้ทำหน้าที่อะไร

เว็บไซต์ Complaint Helper เป็นเครื่องมืออิสระสำหรับค้นหาช่องทางที่อาจเกี่ยวข้อง จัดข้อมูล สร้างข้อความร้องเรียนเบื้องต้น ตรวจความครบถ้วน และช่วยร่างข้อความสอบถามความคืบหน้าและแสดงช่องทางติดตามทางการ โดยไม่ได้ตรวจสถานะเรื่องร้องเรียนจากระบบหน่วยงาน ไม่ใช่เว็บไซต์ของหน่วยงานราชการ และไม่รับหรือส่งคำร้องแทนหน่วยงานใดโดยอัตโนมัติ

2. ข้อมูลที่คุณกรอกถูกเก็บที่ไหน

ข้อมูลในแบบฟอร์มเตรียมคำร้อง เช่น ชื่อผู้ร้องเรียน รายละเอียดเหตุการณ์ จำนวนเงิน และข้อมูลผู้ประกอบการ ถูกใช้เพื่อสร้างคำร้องและบันทึกแบบร่างผ่านพื้นที่จัดเก็บภายในเบราว์เซอร์ (localStorage) ของอุปกรณ์ที่ใช้งาน ส่วนเครื่องมือค้นหาหน่วยงานและร่างข้อความติดตามเรื่องใช้ค่าที่กรอกเพื่อแสดงผลในหน้าเว็บเท่านั้น ไม่บันทึกเป็นแบบร่างและไม่ส่งเนื้อหานั้นไปเก็บที่เซิร์ฟเวอร์ของเว็บไซต์

แบบร่างจะยังอยู่จนกว่าคุณจะกดล้างข้อมูล หรือเบราว์เซอร์/อุปกรณ์ลบข้อมูลเว็บไซต์เอง การบันทึกในเบราว์เซอร์ไม่ได้เข้ารหัสแยกต่างหากโดยเว็บไซต์ จึงไม่ควรใช้เครื่องสาธารณะหรือเครื่องที่ผู้อื่นเข้าถึงได้

3. ไฟล์หลักฐาน

เมื่อคุณเลือกไฟล์หลักฐาน เว็บไซต์จะตรวจข้อมูลพื้นฐานของไฟล์ เช่น ประเภท ขนาด และชื่อไฟล์ในเบราว์เซอร์ เพื่อช่วยจัดรายการหลักฐาน ไม่ได้อัปโหลดเนื้อหาไฟล์ไปยังเซิร์ฟเวอร์ของเว็บไซต์

ไฟล์ที่เลือกจะไม่ได้ถูกเก็บเป็นไฟล์แนบในแบบร่าง หากรีเฟรชหน้าเว็บหรือปิดหน้าเว็บ คุณอาจต้องเลือกไฟล์ใหม่อีกครั้ง

4. บริการภายนอกและข้อมูลการเชื่อมต่อ

เว็บไซต์เผยแพร่ผ่าน GitHub Pages และโหลดชุดข้อมูลจังหวัด อำเภอ ตำบล และรหัสไปรษณีย์จาก GitHub Raw Content เพื่อให้เลือกที่อยู่ได้สะดวก การเปิดหน้าเว็บหรือโหลดข้อมูลดังกล่าวอาจทำให้ผู้ให้บริการโครงสร้างพื้นฐานได้รับข้อมูลการเชื่อมต่อทางเทคนิค เช่น IP Address ตามนโยบายของแต่ละบริการ

เว็บไซต์ไม่ได้ส่งข้อมูลที่คุณพิมพ์ในแบบฟอร์มไปพร้อมกับการร้องขอข้อมูลที่อยู่ดังกล่าว

เมื่อกดลิงก์ไปยัง สคบ. 1212 ETDA กสทช. คปภ. ธปท. หรือบริการอื่น คุณจะออกจากเว็บไซต์ของเรา และการใช้ข้อมูลหลังจากนั้นเป็นไปตามนโยบายของเว็บไซต์ปลายทาง

5. สถิติการใช้งาน

เว็บไซต์ใช้บริการ Umami Cloud เพื่อวัดจำนวนการเปิดหน้าเว็บ และเหตุการณ์การใช้งานที่กำหนดไว้ล่วงหน้า เช่น เริ่มทำคำร้อง เลือกทางลัด ไปถึงหน้าผลลัพธ์ คัดลอกข้อความ หรือกดลิงก์ไปยังหน่วยงานทางการ โดยระบบส่งเฉพาะชื่อเหตุการณ์ ไม่ส่งชื่อ นามสกุล ที่อยู่ เบอร์โทร เนื้อหาคำร้อง จำนวนเงิน ชื่อผู้ถูกร้องเรียน หรือไฟล์หลักฐานไปเป็นข้อมูลเหตุการณ์

การใช้บริการวิเคราะห์สถิติอาจมีการประมวลผลข้อมูลการเชื่อมต่อและข้อมูลการเยี่ยมชม เช่น IP address ระหว่างการเชื่อมต่อ เส้นทางหน้าเว็บ เว็บไซต์ที่อ้างอิง อุปกรณ์ เบราว์เซอร์ และประเทศโดยประมาณ ตามการทำงานและนโยบายของ Umami Cloud โดยไม่ใช่การส่งข้อมูลที่กรอกในคำร้อง เว็บไซต์ตั้งค่าให้เคารพสัญญาณ Do Not Track และปิดการติดตามส่วนค้นหาใน URL

ผู้ให้บริการสถิติคือ Umami Cloud (https://umami.is) ข้อมูลสถิติเก็บตามภูมิภาคที่ผู้ดูแลเลือกในบริการ Umami หากคุณไม่ต้องการให้มีการวิเคราะห์การเข้าใช้ สามารถใช้การตั้งค่าความเป็นส่วนตัวหรือ Do Not Track ของเบราว์เซอร์ได้

6. วิธีลบแบบร่าง

คุณสามารถกดปุ่ม “ล้างข้อมูลทั้งหมด” ในหน้าผลลัพธ์ของแบบฟอร์มเพื่อลบแบบร่างที่เว็บไซต์บันทึกไว้บนเบราว์เซอร์นี้ หรือใช้การตั้งค่าเบราว์เซอร์เพื่อลบข้อมูลเว็บไซต์

การลบแบบร่างไม่สามารถย้อนคืนได้ และจะไม่ลบข้อมูลที่คุณนำไปคัดลอก ส่งต่อ หรือยื่นผ่านเว็บไซต์หน่วยงานอื่นแล้ว

7. ข้อควรทราบก่อนนำคำร้องไปใช้

โปรดตรวจสอบชื่อ วันที่ จำนวนเงิน และข้อเท็จจริงในข้อความที่สร้างขึ้นทุกครั้ง ระบบเลือกช่องทางร้องเรียนเป็นเพียงคำแนะนำเบื้องต้น ไม่ใช่คำวินิจฉัยทางกฎหมายหรือการรับประกันว่าหน่วยงานจะรับเรื่อง
